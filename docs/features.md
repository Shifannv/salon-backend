# Features

## MVP Features

### 1. Authentication

Customer can:

- Sign up
- Log in
- Log out
- Recover password
- Stay logged in using session handling

### 2. Customer Profile

Customer can:

- View profile
- Edit name
- Edit phone number
- Edit basic personal details

### 3. Salon Discovery

Customer can:

- View salon list
- Search salons
- Filter salons
- View nearby salons using current GPS location
- Open salon details

### 4. Salon Details

Customer can:

- View salon name
- View salon images
- View address
- View rating
- View service categories
- View available services
- View starting prices

### 5. Services

Customer can:

- View service name
- View price
- View duration
- Select service for booking

### 6. Booking Flow

Customer can:

- Select salon
- Select service
- Select date
- Select time slot
- Confirm booking
- See booking success state

### 7. Appointments

Customer can:

- View upcoming appointments
- View past appointments
- View appointment details
- Cancel appointment when allowed

### 8. Notifications

Customer can:

- Receive booking confirmation notification
- Receive cancellation notification
- Receive appointment reminder notification
- View notifications list
- See read/unread state

### 9. Current Location

Customer can:

- Allow location permission
- Deny location permission
- Use current GPS location for nearby salon discovery

## Future Features
